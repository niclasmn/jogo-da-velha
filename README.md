## 🎮 Como Jogar?
* **Modos de Jogo:** No menu superior, escolha entre jogar contra um amigo no modo **2 Jogadores (PVP)** ou disputar contra a inteligência do sistema no modo **Contra o Computador**.
* **Formatos de Partida:** Selecione o formato de **Partida Única** para jogos rápidos ou o modo **Melhor de 3 (MD3)** para jogar um torneio de até 3 rodadas, onde o primeiro a conquistar 2 vitórias é consagrado campeão.
* **Mecânica de Jogo:** Clique em qualquer casa disponível do tabuleiro 3x3 para marcar seu símbolo. O primeiro participante a jogar sempre utiliza o símbolo **X**.
* **Condição de Vitória:** O objetivo é alinhar 3 símbolos idênticos em sequência na horizontal, vertical ou diagonal. Caso o tabuleiro fique cheio sem nenhum alinhamento completo, a rodada terminará empatada.
* **Reiniciar Partida:** Clique no botão **REINICIAR JOGO** a qualquer momento para zerar o placar e reiniciar o tabuleiro.
